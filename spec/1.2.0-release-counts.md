# v1.2.0 release notes — the counts and the commands that derive them

The opening of `spec/1.2.0-release-notes.md` quotes four figures. They move with every commit, so
re-run these at the tag and copy the output into the notes; the notes carry the figures, this file
carries the commands. Run from the repository root with `bash`.

## 1. Specs that grew during review

```bash
for s in $(ls spec/.tp-review/*/snapshot-round-1.md spec/backlog/.tp-review/*/snapshot-round-1.md 2>/dev/null); do
  base=$(basename "$(dirname "$s")"); dir=$(dirname "$(dirname "$(dirname "$s")")")
  spec="$dir/$base.md"; [ -f "$spec" ] && ./scripts/check-spec-growth.py "$spec" >/dev/null 2>&1
  echo "$? $spec"
done | awk '{n++; if ($1==1) g++; else if ($1==0) f++} END {print g" of "n" grew; "f" did not"}'
```

## 2. Share of review dispositions that were `fixed`

```bash
python3 -c 'import json,glob,collections;c=collections.Counter(json.loads(l)["resolved"]["status"] for p in ("spec/.tp-review/*/review-round-*.ndjson","spec/backlog/.tp-review/*/review-round-*.ndjson") for f in glob.glob(p) for l in open(f) if l.strip() and isinstance(json.loads(l).get("resolved"),dict));t=sum(c.values());print(dict(c),t,round(100*c["fixed"]/t,1))'
```

## 3. Commits before and during the release

A commit is **code** when it touches `internal/`, `cmd/`, `hooks/` or `scripts/`, and **spec-only**
when every file it touches is under `spec/`. Commits touching only the release notes are not counted. `6f8e8564` is the last commit before 2026-09-09;
`d441deaa` is the release's first commit.

```bash
python3 - <<'EOF'
import subprocess
def count(rng):
    out = subprocess.run(["git", "log", "--no-merges", "--format=@%H", "--name-only", rng],
                         capture_output=True, text=True).stdout
    code = spec = 0
    for block in out.split("@")[1:]:
        files = [f for f in block.split("\n")[1:] if f.strip()]
        if files and all(f.startswith("spec/1.2.0-release-") for f in files):
            continue  # the release notes' own commits
        if any(f.startswith(("internal/", "cmd/", "hooks/", "scripts/")) for f in files):
            code += 1
        elif files and all(f.startswith("spec/") for f in files):
            spec += 1
    return code, spec
print("before (code, spec-only):", count("6f8e8564..d441deaa^"))
print("release (code, spec-only):", count("d441deaa^..HEAD"))
EOF
```
