# tp v1.4.2 — an honest open count

> The release notes for the `v1.4.2` tag. Publishing is a separate, human decision.

## Fixed

- **`tp epic review --status`'s `open` counts only undecided findings.** It counted every row of the
  last round, so a finding already resolved `fixed` still showed as open. A `fixed` finding waits for
  the next round to read the change, not for a decision, and is no longer counted.
