# 1.22.3 measurements

A cleanup patch after v1.22.2: a stale park closed, an unreachable path removed, and the mutants
v1.22.2's run left in the task-audit code given engine-level tests.

## The divisible round, closed

`spec/undecided.md` still parked *The divisible round* with its next step, one constructed audit
round over the full file list. That round ran in v1.21.1 (`spec/1.21.1-measurements.md`) and its
answer shipped in v1.22.0 as the task audit (`spec/1.22.0-measurements.md`), so the entry moved to
*Decided — closed* with a reopen condition, and `BUGS.md`'s cut entry points at it.

## The zero-file task audit path

`freezeNextTaskAudit` recorded a batch with no file at once and looped. No due batch can be empty:
`owedTaskAuditPieces` keeps only candidates with a file left (after `dropGradedFiles`), and a
re-grade with no file is not due. Probe: the path replaced by a panic, then the `internal/cli` and
`internal/engine` suites run; neither reached it. The path and its loop are removed.

## Mutation survivors

v1.22.2's engine run (`spec/1.22.2-measurements.md`) left 42 survivors. Most were package scope: the
task-audit scheduling is exercised from `internal/cli`, and `TP_MUT_PKGS=internal/engine` runs only
the engine's own tests. Engine tests in `internal/engine/taskaudit_units_mutants_test.go` close the
gap; each was run on HEAD, then under each of its mutants applied by hand, and seen red.
