# tp 1.12.0 — the cycle

1.12.0 closes every entry of `BUGS.md`'s fix track. Two were plain fixes; five were decisions, each
with its note in `spec/backlog/` and built in one clone, one commit series per unit, under one review
of two roles over two rounds.

## The plain fixes

- **The dropped roles-hash error** was real on five paths. Review and audit record and status now
  exit 3; `tp run --status` keeps its "omit the signals" contract and names the error, since an
  omission with no reason was the same silence the entry described.
- **The flaky hook-bound test** was a race in the test's liveness probe: `kill(pid, 0)` succeeds on a
  zombie, and a reaper between that call and the `/proc` read made a collected process look alive.
  A deterministic test reaps a zombie between the two probes. Unconfirmed on a Linux runner until a
  release job passes without a rerun.

## The decisions

- **Regression under `tp run`.** Only spec review's panel carries it. The oracle and the emission now
  share one predicate, and a test over the whole panel asserts every emitted prompt has a unit.
- **Staleness.** The stop rule for this unit asked whether histories from before v1.2.2 could be told
  apart from hand-recorded ones; they can (the former carry no scheme mark, the latter a
  `no-emission` mark), and every spec in tp's own repository reported the same status before and
  after. The entry said seven tests pinned the fallback; thirty-six did, which is the case for
  counting a quantifier before writing it.
- **Ground scratch.** The check its note asked for found the same collision in `tp run`'s round
  directories, which were keyed by base alone; those, and the run's state files, are now keyed by
  location.
- **Project layer.** Review round 1 found a high: `tp run <spec>` naming another project's spec was
  not refused, because the side check resolved the task file by a different route than the
  command. The fix removed the class: each command refuses through the task file it resolved
  itself, and a test drives every in-tree mode by every route a task file can arrive by. The
  refusal is exit 3, since exit 2 means "escalate an operator decision" under a run. A `.tp/` that
  only side effects created is recognised by its entries, not by the bytes of a file tp writes.
- **Role files.** Added by the operator during the cycle: review and audit role files took the same
  remedy as the ground scratch file.
