# 1.22.1 measurements

A fix-track patch: the four defects the 1.22.0 field run and review found in code older than that
release (`spec/1.22.0-measurements.md`). Each was reproduced with a freshly built binary in a scratch
project before its test was written, and each test was seen red for the reason reproduced.

| Defect | Reproduced | Fix |
|--------|------------|-----|
| `tp done` stored `commit_files` in the C-quoted form git prints for a path outside plain ASCII or holding a quote (`ü.go` as `"\303\274.go"`) | yes: a commit of `ü.go` and `plain.go` recorded the quoted name | `git show --name-status -z`, read NUL-separated; the sha is guarded with `SafeGitRev` at that sink, which it was not |
| `tp import --force` over a task file that exists and cannot be read wrote over it, dropping its `epic` binding and `workflow` block at exit 0 | yes: `epic: e1` and the workflow override were gone after the import | the import refuses at exit 3 and writes nothing, `--force` included |
| The dashboard's plan figures fall back to the default placeholder pattern without a warning | **no**: on the same tick the `epic export` derivation prints the warning once (`TestDashboard_WarnsOnceAboutAnUncompilablePlaceholder`), and both run only with a graph | none; closed as not reproduced |
| An epic review round file that could not be read or parsed was reported without its cause, at seven sites | yes: an unparseable line gave only "cannot be read as NDJSON" | one reader wraps the read error or names the line and its JSON error |
