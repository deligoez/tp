# tp 1.17.0 — measurements: one graph card

What 1.17.0 measured while taking the graph card of `spec/backlog/dashboard-graph.md` from a
prototype to a release. Every number comes from a synthetic graph built for this note, at a size
picked to be unrelated to any project and to test scale; none comes from a requesting project.

## The synthetic graph

Generated by a seeded script: 819 epics (808 work epics and 11 conditions) in 20 milestones over
five tracks of 5, 4, 2, 5 and 4 milestones, two of them trigger milestones; 3,141 edges once each
any-of member counts; 60 described epics; two bound specs, one with a claimed task. One title holds
every Turkish letter the page must draw.

| `/api/layout` view | nodes | edges | tree | cross | critical (of them cross) | layers × columns | payload | answer |
|---|---:|---:|---:|---:|---:|---|---:|---:|
| `plan` (rows) | 819 | 3,141 | 786 | 2,355 | 114 (8) | 161 × 65 | 424 KB | 21-29 ms |
| `plan&pack=tree` | 819 | 3,141 | 786 | 2,355 | 114 (8) | 161 × 278 | 428 KB | 21 ms |
| `scope&milestone=A3` | 101 | 333 | 96 | 237 | 63 (4) | 66 × 27 | 43 KB | 21-22 ms |
| `neighbourhood&epic=api-gw-replay`, depth 2 | 60 | 112 | 56 | 56 | 0 | 18 × 15 | 20 KB | 16-17 ms |
| `milestones` | 20 | 18 | 17 | 1 | 0 | 6 × 4 | 5 KB | 16 ms |

No back edge: the generated graph has no milestone cycle. Answers are three runs each over loopback.

## The draw check

After every frame deck.gl renders, the card records the mode and the nodes and edges it drew as
`data-drawn-mode`, `data-drawn-nodes` and `data-drawn-edges`; the screenshot audit read them for
every shot. The nodes are always the layout's. The edges are the layout's that `tpPure.edgeLayers`
keeps: every edge with cross edges shown, and with them hidden every edge but the plain cross ones,
the critical path kept whatever its class.

| Mode | drawn nodes | drawn edges | the layout's count it must equal |
|---|---:|---:|---|
| Plan, cross edges off | 819 | 794 | 786 tree + 8 critical cross |
| Gate closure A3, cross off | 101 | 100 | 96 tree + 4 critical cross |
| Gate closure A3, tree packing, cross on | 101 | 333 | 333 |
| Neighbourhood, depth 2 | 60 | 56 | 56 tree |
| Milestones | 20 | 17 | 17 tree |

Every shot at every viewport read the same counts. A blank canvas leaves `data-drawn-nodes` at the 0
the page ships with: the no-WebGL2 fallback (`?nogl=1`) read 0, with its message shown and no
deck.gl script on the page.

**Critical path with holes, fixed.** The prototype hid every cross edge, critical or not, so with
cross edges off the critical path drew in pieces. Eight of the plan's 114 critical edges and four of
A3's 63 are cross edges; 1.17.0 draws them (decision 2), pinned by
`TestPure_ACriticalEdgeIsDrawnWhateverItsClass`.

## Plan mode's first draw, in the page

`data-first-draw-ms` is the time from the card asking for the renderer to the first frame holding
nodes: loading deck.gl, fetching the plan's layout, preparing 819 nodes and 3,141 edges, drawing.
Measured in a fresh headless Chromium (agent-browser) over loopback:

| Viewport | first draw | of which the renderer loaded |
|---|---:|---:|
| 1920 × 1080 | 161 ms | 32 ms |
| 1440 × 900 | 163 ms | 31 ms |
| 390 × 844 | 157 ms | 32 ms |
| 1920 × 1080, reload into Gate closure A3 | 125 ms | 21 ms |

Loopback hides the download; the renderer is 470 KB on the wire (below).

## Sizes

| | bytes |
|---|---:|
| `deckgl-9.3.12.min.js`, npm's `dist.min.js` | 1,648,511 |
| the same, gzip -9, as embedded and served | 470,246 |
| stripped binary at v1.16.0 plus the decision note (6b441349) | 12,870,130 |
| stripped binary, the prototype (deck.gl embedded uncompressed) | 14,554,818 |
| stripped binary, 1.17.0 | 13,416,914 |

`go build -ldflags="-s -w"`, go1.27.4, darwin/arm64. Storing the bundle compressed takes the
renderer's cost from 1.68 MB to 0.55 MB of binary. CLAUDE.md's "<10MB" was already false at 1.16.0
(12.9 MB); it now says <14MB with these numbers. A client that sends `Accept-Encoding: gzip` gets
the stored bytes with `Content-Encoding: gzip`, any other gets them decompressed
(`TestHandler_ServesTheRendererGzippedOrPlain`). The sha256 of the decompressed bytes,
`9a58a99e…f108`, equals the file in npm's `deck.gl-9.3.12.tgz`, whose `sha512` integrity was checked
against the registry (`page/vendor/PROVENANCE.md`).

## The address

The card's place is six keys, each written only when it is not the default: `gv` the mode
(`milestones`, `scope`, `neighbourhood`), `gm` the gate milestone, `gd` the depth, `pack=tree`,
`cross=1` and `q` the search. `gv` and `gm` are places (a history entry each); the rest replace the
current entry. Measured: after Gate closure, A3, cross edges and tree packing the address read
`#tab=epics&gv=scope&gm=A3&pack=tree&cross=1`; a reload restored all of it and drew the same 333
edges; back went to `gv=scope` (the default gate, 34 edges), back again to the plan (794), and
forward returned to `gv=scope`.

## The keyboard trade (decision 4)

The canvas has no focusable node. Checked in the browser on the plan: with the canvas box focused,
two arrows and + moved the view target from (5471, 3112) to (6246, 3887) and the zoom from −3.11 to
−2.61; `/` moved focus to the graph's search, not the Specs filter; typing put `q=replay` in the
address and Esc there cleared the search and the key; typing `model` and Enter selected the first
match, centred it at zoom 0 and opened the drawer; Esc closed the drawer, cleared the selection and
gave focus back to the search. A list or drawer link selects and centres through
`tpApp.onSelect(id, true)`. The selected epic's chain stays a collapsible text list under the canvas
(`#chaintext`), with every edge's why.

## Known, left for later

- **Long horizontal tree edges under `pack=rows`.** The squeeze places each layer on its own, so a
  child can land far from its parent and its tree edge runs across the band. A fix aims each node at
  its parent's squeezed column, which changes the row-packing golden; it is a layout decision, not a
  polish.
- **Bands of different tracks can still overlap** where a layer's squeeze pulls one track's nodes
  under another's band. The per-layer outline narrows it; separating tracks inside a layer is the
  same layout decision.
- **The toolbar wraps** to a second line at 1920 × 1080 when Gate closure's count line is long.
- **The renderer loads in tens of milliseconds on loopback**; over a slow link its 470 KB is the
  first-draw cost, with the card's message shown meanwhile.
