# tp v1.6.2 — an unknown commit strategy is refused, and a faster mutation run

> The release notes for the `v1.6.2` tag. Publishing is a separate, human decision.

A fix-track patch: the defect `BUGS.md` recorded after v1.6.1, and the boundary tests the
pre-release mutation run of the v1.6.0 epic surface asked for.

## Fixed

- **`tp init --commit-strategy` refuses a value it does not know.** It exits 2 naming the valid
  values (`builtin`, `auto`, `hc`) and writes no task file; before, the value was stored and the
  mistake surfaced only later, as a warning on the commands that read the strategy.
  `tp set --workflow --project commit_strategy=` already refused one, with exit 1, and is unchanged.

## Tests

The mutation run over the engine files v1.6.0 changed left 86 mutants alive. Classified, 15 were
equivalent and 2 changed only an undocumented detail (a singular or plural word); those 17 are the
committed baseline. The other 69 changed a stated contract no engine test noticed; the tests written
for them reached 4 mutants no test had covered, which survived too, and thirteen new engine tests now
kill all 73. No defect was found; what was untested:

- the `audit-budget-exhausted` blocker at the audit cap, and when the epic-blocked blocker fires;
- an epic block: a dependency at the head of the graph or absent from it, one derived done from its
  bound files, a single tag, and when it names the operator's action;
- a condition nothing depends on counting as actionable;
- downstream counts per milestone through conditions, and on a graph past 64 epics;
- the whole-graph critical path's head, ties and cycles;
- the epic lint's two-epic dependency cycle, and the milestone wait cycle's rotation, members and
  the milestone its message names;
- gate units for a set slice of one epic and for an epic slice.

## Development

- **The pre-release mutation run is `scripts/mutation.sh`.** It runs go-mutesting with per-test
  selection over the Go files changed since the last tag, in a fresh copy, and keeps its reports
  under `~/.cache/tp-mut`. Measured on the v1.6.0 engine surface it reached the same verdict for
  every mutant as a whole-package run in under a third of the time (`docs/lessons.md`).

The plugin version moves to 1.6.2: `skills/tp/REFERENCE.md` now says both writers refuse an
unrecognized commit strategy.
