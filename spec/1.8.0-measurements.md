### The `/api/export` containment, round by round

The one endpoint that takes a path from the request went through four designs:

1. **A lexical check** (`filepath.Abs` then a prefix test). Round 1 found a missing path through an
   in-repo symlink leading out answered 404, not 403 (`05ba6814`: resolve through the nearest existing
   ancestor). Round 3 found the bypass: the check cleaned `lnk/..` lexically while the open followed
   the symlink first.
2. **`os.Root`** (`6f4b0660`): the task file's bytes read through the repository's root, escape
   refused in the same operation as the read. Round 5: `os.Root` follows at most eight symlinks and
   answers ELOOP, which fell through to an unguarded read by the raw path.
3. **Fail closed** (`2972285b`): the path resolved component by component as the OS does, and any
   undecidable case refused. Round 6: the task file was guarded, but the spec it names and the round
   state beside it were still read through the raw path.
4. **An allow-list** (`cf1f2e84`, operator decision): `?file=` must be byte-equal to a path
   `tp export --list` prints, and is answered by `tp export --file`'s own code; no request-supplied
   path is resolved, and the path-resolution code was deleted. Rounds 7 and 8 found only the base the
   listed path is read from (the server's working directory, then a symlinked one); both fixed.

The allow-list's first build derived the whole list per request. Measured with curl on a synthetic
repository of 300 task files, one GET of `/api/export` (`307c2584`'s body, three runs): before
16.4 s, 11.1 s, 8.1 s; after deciding membership from `git ls-files` alone, 0.050 s, 0.042 s,
0.041 s. Round 8's auditor measured 0.041 s per GET at 300 files.

## Known limits at the tag

- **SSE derivation cost with hundreds of task files.** Each tick, every 2 seconds while a page
  listens, derives the `export-list` payload, which reads every task file and builds its resume view.
  Round 7's auditor measured that whole-list derivation at about 8 s for 300 task files (per request,
  before `307c2584` took it off `/api/export`); the event stream still pays it per tick, shared by one
  hub across listeners. Not measured further in this cycle.
- **An unreadable listed file's error from a subdirectory.** Below the root, a listed task file is
  opened by its absolute path (`4a0613d3`), and a file gone since it was listed is named as
  `tp export --file` names it at the root; the spelling of other read errors from a subdirectory was
  not compared with the command's.
- **The dropped roles-hash error** (`BUGS.md`): `engine.ComputeRolesHash`'s error is discarded on four
  record and status paths, present since July, outside this release's surface, not yet reproduced.
- **`tp audit --status` does not read converged** for this spec (above); the release ships on spec
  conformance, as rule 13 allows.
